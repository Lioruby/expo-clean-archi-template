Git Add, Commit and Push automatique

## Instructions

Exécute les étapes suivantes pour commit et push les changements sur la branche actuelle :

1. **Analyse les changements** :
   - Exécute `git status` pour voir les fichiers modifiés/ajoutés
   - Exécute `git diff` pour voir le contenu des changements
   - Exécute `git log -5 --oneline` pour voir le style des commits récents

2. **Stage les fichiers** :
   - Ajoute tous les fichiers pertinents avec `git add`
   - Exclue les fichiers sensibles (.env, credentials, etc.)

3. **Crée le commit** :
   - Rédige un message de commit concis et descriptif basé sur les changements
   - Utilise le format conventionnel : `type: description`
     - `feat:` nouvelle fonctionnalité
     - `fix:` correction de bug
     - `refactor:` refactoring sans changement de comportement
     - `chore:` maintenance, dépendances, config
     - `docs:` documentation
     - `test:` ajout/modification de tests
   - Termine le message avec le footer standard

4. **Push les changements** :
   - Push sur la branche actuelle avec `git push`
   - Si la branche n'existe pas sur le remote, utilise `git push -u origin HEAD`

## Règles importantes

- Ne demande PAS de confirmation à l'utilisateur, exécute directement
- Si les hooks pre-commit échouent, corrige les erreurs et recommence
- N'utilise JAMAIS `--force` ou `--no-verify`
- Si aucun changement n'est détecté, informe l'utilisateur et arrête
- Ne SIGNE PAS le commit (pas de "generated by claude code" ou autre signature)
